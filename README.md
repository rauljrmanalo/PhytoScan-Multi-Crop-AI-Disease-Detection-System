# PhytoScan – Multi-Crop AI Disease Detection System

## Overview

PhytoScan is an AI-powered web application designed to assist farmers and agricultural professionals in identifying plant diseases through image analysis. Users can upload an image of a crop leaf, and the system uses machine learning and computer vision techniques to detect potential diseases and provide a confidence score for the prediction.

The platform currently supports disease detection for five major crops:

- Rice
- Chilli
- Corn
- Banana
- Onion

By providing fast and accessible disease identification, PhytoScan aims to support early intervention, improve crop management, and reduce agricultural losses.

## Problem Statement

Plant diseases are one of the leading causes of reduced agricultural productivity worldwide. Accurate disease diagnosis often requires expert knowledge, which may not always be available to farmers, particularly in remote areas.

PhytoScan addresses this challenge by providing an accessible AI-based solution that enables users to identify diseases from crop images quickly and efficiently using a web application.

---

## How It Works

1. Select the crop type.
2. Upload an image of the crop leaf.
3. The image is preprocessed and prepared for analysis.
4. The trained AI model analyzes the image.
5. The system predicts the most likely disease category.
6. Results are displayed along with a confidence score.
